# Windows Client

Future Windows desktop application for Leo AI.

## Responsibility

- Display the assistant interface on a Windows laptop.
- Receive user commands (text and eventually voice).
- Interact with the local Windows system through controlled tools.
- Communicate with the Leo AI backend API.

## Status

**PLANNED** — Not yet implemented. No desktop shell technology (Electron, Tauri) has been selected.
